# 행위 분류 목록 — timeline.csv 의 User_behavior 에 허용되는 이름 (한 줄에 하나, # 은 주석)
# 파서 6개는 이 이름만 쓴다. 근거·상태 설명(프리패치, 로그인 상태 확인 등)은 Behavior_details / Artifact_details 에 쓴다.
# 목록 밖 이름은 통합기가 UNKNOWN_USER_BEHAVIOR 경고로 보고한다 (적재는 함). 새 행위는 여기에 먼저 추가한 뒤 파서가 쓴다.
# 행위명에 서비스명을 넣지 않는다 (어느 서비스인지는 Model 열이 말한다). 예: "Claude 로그인" 이 아니라 "로그인".
# 실제로 실험해 확인한 행위만 둔다. 서비스 URL 을 방문한 흔적은 행위로 내지 않는다.
#
# 매핑 규칙
# - 계정·조직 식별자를 확인한 흔적은 로그인 + 의심. 식별자는 Behavior_details 에 적는다.
# - 프리패치 실행 기록은 애플리케이션 실행. 앱 로그의 종료 기록은 정상 종료 (강제 종료 근거가 없으면).
# - 프롬프트 초안은 사용자 프롬프트 입력/전송 + 의심.
# - 종류를 확인할 수 없는 다운로드는 문서 다운로드 로 내고 사유를 Behavior_details 에 적는다.
